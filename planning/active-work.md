# Contribution coordination

Use public issues and pull requests to coordinate current work. The
[contribution guide](../CONTRIBUTING.md) explains the expected scope and checks.
The [development priorities](../docs/next-development.md) identify known gaps.

The backlog is the design package graph, not an automatically synchronized issue
tracker or a claim that every acceptance gate has passed. Agree on shared API,
storage, permission and native-account changes before editing overlapping areas.
Private worker assignments and machine-specific worktrees are not published.
